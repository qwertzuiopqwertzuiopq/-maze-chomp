# Maze Chomp

A simple browser game built as a static GitHub Pages project.

## Play locally

From the project root:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## How to play

- Use the arrow keys or WASD to move.
- Collect pellets to increase your score.
- Eat glowing power pellets to scare ghosts temporarily.
- Clear the maze to advance to the next level.

## GitHub Pages

This project is designed to work as a static site from the repository root, so it can be published directly with GitHub Pages.
